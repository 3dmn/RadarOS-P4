ESP32-P4 STANDALONE ADS-B

RadarOS-P4 Web Installer

Zainstaluj oprogramowanie bezpośrednio z przeglądarki bez konieczności instalacji ESP-IDF czy Python.

Twoja przeglądarka nie obsługuje Web Serial API.
Otwórz tę stronę w Google Chrome, Microsoft Edge lub Brave na komputerze.
Instrukcja instalacji:
  1. Podłącz płytkę Waveshare ESP32-P4 kablem USB do portu UART.
  2. Kliknij powyższy przycisk instalatora.
  3. Wybierz port COM urządzenia i zatwierdź (Connect).
  4. Wybierz Install RadarOS-P4 i zaznacz opcję wyczyszczenia pamięci (Erase).
