ESP32-P4 STANDALONE ADS-B

RadarOS-P4 Web Installer

Flash the firmware directly from your browser without installing ESP-IDF, toolchains, or Python.

Your browser does not support the Web Serial API.
Please open this page in Google Chrome, Microsoft Edge, or Brave on desktop.
Instructions:
  1. Connect the Waveshare ESP32-P4 board to your computer via the UART USB port.
  2. Click the button above to launch the installer.
  3. Select your device's COM port from the popup and click Connect.
  4. Select Install RadarOS-P4 and enable the Erase device option for a clean flash.
